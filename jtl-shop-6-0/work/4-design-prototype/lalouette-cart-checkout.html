L’alouette — Cart & Checkout

Storefront purchase flow for JTL-Shop 6.0, drawn in the existing L’alouette design language (orange header chrome, navy footer, flat white page, ink primary buttons). Twelve frames: cart, a four-step checkout, and the order confirmation — desktop 1440 and mobile 390.

Viewing note: frames scale down to fit a narrow window; widen the window (or open the file in a browser) to see them at full size. The scaling is display-only — the frames are still 1440 and 390.

Frame 00 below is a token sheet. Build colour variables and text styles from it before generating the screens, so every frame references the same set. Every other frame is a finished screen; sample data is consistent across all of them (order LA-2026-018472, total €366.00).
