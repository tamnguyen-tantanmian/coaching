Theme assistant — floating AI chat

The AI chat floats over the Theme Setup screen in the bottom-left corner. It isn't part of the theme list, canvas or inspector, so it stays available while you work and can be minimized to a button.

Core flows

Seven flows the assistant needs. Each one becomes several screens later; for now these set the scope. Must = needed for the first release.

1Ask → Preview → ApplyMust

The main path. Every other flow comes back to it.

Ask AI button→Empty + suggestions→Prompt / upload image→Thinking→Proposal card→Preview on canvas→Applied + Undo
2Refine a proposalMust

The user adjusts the AI's answer instead of accepting or rejecting all of it.

Proposal card→Untick changes (partial)→or Discard→Follow-up prompt→New proposal
3AI asks before actingMust

For ambiguous requests or ones the assistant can't do.

Vague prompt→Clarifying question→Pick an option→Proposal
Out-of-scope prompt→Explain + link to the right place
4Guardrails before ApplyShould

Protects the shop from bad results without blocking the merchant.

Proposal→Contrast warning→Apply suggested fix→or Apply anyway
Theme edited by hand→Outdated proposal→Regenerate
5Work in the backgroundShould

Floating panel can be minimized while the AI keeps working.

Prompt sent→Minimize→Button: working→Bubble: answer ready→Preview / Open chat
6Recover from failureMust

One pattern for all errors: keep the message, explain, offer one next step.

Error→Retry
Stopped→Continue
Bad image→Re-upload
Rate limit→Wait (proposals still usable)
7Come back laterLater

Return to earlier chats for this theme.

History list→Open past chat→Proposal status (applied / not / discarded)

Interactive prototype

Try "Apply my brand colors", then Preview → Apply → Undo. Minimize with the chevron and reopen with the button. ■ stops a reply that's still thinking.
