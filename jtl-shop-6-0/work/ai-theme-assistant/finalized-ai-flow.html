#Rule · Scenario / Quy tắc · Kịch bảnFlow / Luồng
R1
In memory
In memory
In every case, the AI runs and writes the changes into In memory — a temporary copy on the FE that is lost on reload (FE handles this).
Trong bất kỳ trường hợp nào, AI sẽ chạy và cập nhật thay đổi vào In memory — tức là một bản lưu tạm trên FE, reload thì sẽ mất (phương án xử lý: FE handle).
R2
Request allow permission
Request allow permission
The session runs to the end, and only then is the flow closed with a Request allow permission:
  • Theme settings: 3 buttons Apply changesSave as draftDismiss
  • Theme builder: 2 buttons Apply changesDismiss → once this session is done, a follow-up request “Do you want to publish it” PublishDeny
  • Apply changes: the system runs underneath Save as version › Apply this theme › Save as version (in the page builder, if any) accordingly.
Session chạy đến cuối cùng mới chốt flow bằng Request allow permission:
  • Theme settings: hiện 3 buttons Apply changesSave as draftDismiss
  • Theme builder: hiện 2 buttons Apply changesDismiss → xong session này sẽ hiện tiếp request “Do you want to publish it” PublishDeny
  • Apply changes: hệ thống chạy ngầm Save as version › Apply this theme › Save as version (trong page builder nếu có) tương ứng.
R3
Chat while running
Chat khi đang chạy
While a session is running, the chat is disabled.
Session đang chạy ⇒ chat bị disabled.
S1
Core loop
Luồng chính
Prompt → AI runs → AI asks questions → merchant answers → AI runs and validates again → AI finalizes and shows the changes (tokens, colours, text, structure?) → Request allow permission (R2).
Prompt → AI chạy → AI hỏi lại → merchant trả lời → AI chạy và kiểm tra lại → AI chốt và hiển thị các thay đổi (token, màu, text, cấu trúc?) → Request allow permission (R2).
S2
In Theme settings → change Theme settings
Ở Theme settings → sửa Theme settings
Happy case. AI updates the theme settings and shows the preview.
Happy case. AI cập nhật Theme settings và hiển thị preview.
S3
In Theme settings → change Theme builder
Ở Theme settings → sửa Theme builder
AI session runs → FE updates the UI of that specific page → chat shows the page name + hyperlink → clicking the link switches to the Builder and shows the preview of that page.
Phiên AI chạy xong → FE cập nhật UI của đúng trang đó → chat hiển thị tên trang + hyperlink → bấm link chuyển sang Builder và hiển thị preview trang đó.
S4
In Theme builder → change Theme settings (colour, font tokens)
Ở Theme builder → sửa Theme settings (token màu, font)
AI session runs → FE updates the tokens → chat shows a hyperlink to Theme settings + Request allow permission.
Phiên AI chạy xong → FE cập nhật token → chat hiển thị hyperlink tới Theme settings + Request allow permission.
S5
One prompt for many pages (MVP)
Một prompt sửa nhiều trang (MVP)
Apply changes or Dismiss applies to all pages at once.
Apply changes hoặc Dismiss áp dụng cho tất cả các trang cùng lúc.
